# nna.mn — front-end (Studio UI v2)

Эвэнтийн зургаа царайгаараа олох вэб сайтын харагдах тал. Цэвэр HTML + CSS + JS, build шаардлагагүй.
Backend холбогдоогүй — эвэнт, тоо, үр дүн бүгд жишээ өгөгдөл.

## Хуудсууд
| Файл | Хуудас |
|---|---|
| `index.html` | Нүүр — хайлт, ангилал, постертой эвэнтүүд (утсанд хажуу тийш гүйлгэнэ), хураангуй алхам/үнэ, асуулт |
| `event.html` | Эвэнт — постер, хуваалцах, selfie оруулах карт |
| `upload.html` | 1. Selfie — зөвшөөрөл тэмдэглэсний дараа камер эсвэл зураг сонгох (бодит файл сонгоно) |
| `matching.html` | 2. Хайлт — явц, ~3 сек дараа үр дүн рүү |
| `results.html` | 3. Сонгох — зургийг дарж томруулна (swipe, дарсан газраа zoom), ✓-ээр хасах/нэмэх |
| `checkout.html` | 4. Төлбөр — компьютерт QPay QR, утсанд банкны апп сонгох + буцаж ирэхэд автомат шалгалт |
| `library.html` | Миний зургууд — утсандаа хадгалах (share sheet), нэвтрэх код хуваалцах |
| `ui-kit.html` | Загварын систем (өнгө, фонт, бүрэлдэхүүн) |

## Харанхуй горим
- Анх нээхэд төхөөрөмжийн тохиргоог (prefers-color-scheme) дагана.
- Header дахь сар/нар товчоор солино, сонголт хадгалагдана (localStorage `nna-theme`).
- Бүх өнгө `assets/ui.css` доторх CSS хувьсагч (`--bg`, `--card`, `--ink`, `--blue`…); dark утгууд `[data-theme="dark"]` блокт.

## Vercel дээр байршуулах
1. vercel.com → **Add New → Project** → энэ хавтсыг чирж оруулна (эсвэл GitHub репод хийгээд Import).
2. Framework Preset: **Other** · Build Command: хоосон · Output Directory: `.`
3. Эсвэл CLI: энэ хавтсанд `npx vercel` → `npx vercel --prod`

`vercel.json`-ийн ачаар `/event`, `/results` гэх мэт `.html`-гүй хаяг ажиллана.

## Компьютер дээрээ үзэх
`npx serve .` эсвэл `python3 -m http.server 8000` → http://localhost:8000

## Постер
Эвэнт бүр постероороо танигдана. Одоо `.poster` нь CSS-ээр зурсан орлуулга (`.pin` доторх бичиг).
Жинхэнэ постерыг `.poster` дотор `<img class="pimg" src="…" alt="" loading="lazy">` болгон нэмэхэд орлуулгыг бүрхэнэ.

## Фонт
Onest, JetBrains Mono нь `assets/fonts/`-д өөрийн сервер дээр (OFL). Монгол бичигт cyrillic + cyrillic-ext (Ө, Ү) хоёулаа хэрэгтэй, ₮ нь latin-ext-д байдаг.

## Бодит болгохын өмнө солих зүйлс
Эвэнтийн жинхэнэ зургууд, постерууд (одоо бүдгэрүүлсэн орлуулга) · зургийн тоо · нууцлалын бодлогын текст ·
"selfie 24 цагт устгана", "30 хоног хадгална" нөхцөл · hello@nna.mn · сошиал холбоосууд · QR (жишээ, уншигдахгүй).
- `og:image` нь `https://nna.mn/assets/og.png` гэсэн бүтэн хаягтай — домэйн өөр бол бүх хуудсанд солино. Эвэнт бүрд өөрийн постероор og:image хийвэл Facebook/Messenger дээр илүү танигдана.
- Банкны жагсаалт (`checkout.html`) жишээ. Бодит хувилбарт QPay invoice хариуны `urls[]` (нэр, лого, deeplink)-ээс үүсгэнэ; төлбөрийг callback / `payment/check`-ээр шалгана.
- «Мэдэгдэл авах» утасны дугаарыг SMS илгээх backend-д хадгална.
- «Утсандаа хадгалах» одоо canvas-аар зурсан жишээ зураг хуваалцдаг. Бодит хувилбарт эх зургуудыг хуудас ачаалахад blob болгон татаж бэлдэнэ (`navigator.share` товч дарсан мөчид дуудагдах ёстой).
